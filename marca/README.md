# Marca de BOBT

Elegida el 18-10-2026: moneda verde profundo con aro blanco, plana y minimalista. El tricolor de Bolivia, en
tonos suaves, es solo un adorno (una franja fina), nunca parte del logo. Los SVG tienen la letra convertida a
trazos (Avenir Next Bold), así que se ven igual en cualquier computadora.

| Archivo | Para qué |
|---|---|
| `bobt-moneda.svg` / `-1024.png` / `-512.png` | Ícono del token y del proyecto (APEX, wallets, stellar.toml) |
| `bobt-moneda-64.png` | Favicon e íconos chicos |
| `bobt-logo.svg` / `.png` | Logo completo sobre fondo claro (portada del deck, documentos) |
| `bobt-logo-blanco.svg` / `.png` | Logo completo sobre fondo verde (slides de color, redes) |
| `franja-tricolor.svg` / `.png` | Adorno: franja fina con el tricolor suave |

## Paleta

| Color | Hex | Uso |
|---|---|---|
| Verde profundo | `#00573F` | Color principal: logo, títulos, botones |
| Verde oscuro | `#003D2C` | Fondos oscuros |
| Verde claro | `#E4F0EA` | Fondos de cajas |
| Fondo | `#F6F8F5` | Fondo general (blanco tonalizado) |
| Tinta | `#14211C` | Texto principal |
| Gris verdoso | `#4A5A53` | Texto secundario |
| Tricolor suave | `#D9645A` · `#F2C94C` · `#4FA36B` | Solo adornos |

Tipografía: Avenir Next en el logo. En el deck y la web, Nunito Sans (muy parecida y gratuita en Google Fonts).

## Reglas

- Sin la bandera completa ni el escudo, y nada que se parezca al BCB o a un billete oficial.
- No poner el logo de Stellar dentro del de BOBT; para eso está el sello oficial "Built on Stellar".
- Dejar aire alrededor del logo: como mínimo, el ancho del aro blanco.
